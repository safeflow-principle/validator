# Cloud deployment setup

The public, provider-neutral deployment instructions are maintained in [deployment.md](deployment.md). They cover a fresh Supabase project, Auth redirects, migrations, Vercel build settings, public browser variables, role onboarding, and verification.

This repository intentionally contains no production project reference, domain requirement, SMTP credential, Vercel token, database password, or service-role key. Do not copy values from the hosted SafeFlow service into an independent deployment.

For a fully disposable backend on a developer machine, use [local-supabase.md](local-supabase.md).
